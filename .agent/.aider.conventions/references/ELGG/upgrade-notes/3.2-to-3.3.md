# Plugin Upgrade Notes: 3.2 to 3.3

Delta guidance for updating Elgg plugins from 3.2 to 3.3, distilled from
<https://learn.elgg.org/en/stable/appendix/upgrade-notes/3.2-to-3.3.html>.
The transition raises the PHP requirement, simplifies page rendering with
`elgg_view_page()`, deprecates the legacy layout names, and deprecates a
batch of APIs in favor of service methods.

## PHP version

PHP 7.1 reached end of life in December 2019; new installations now require
PHP 7.2. Make sure the correct PHP version is installed before upgrading an
existing installation. To support testing on PHP 7.4, the PHPUnit testsuite
was updated to version 8.5, which may require rewrites of your own
unit/integration tests.

## Simpler use of the 'default' layout

`elgg_view_page()` now accepts an array of layout options as its second
parameter: it wraps the content in the `default` layout and adds the page
title. This replaces the manual `elgg_view_layout()` + `elgg_view_page()`
pattern:

```php
// before
$title = 'All blogs';

$content = elgg_list_entities([
    'type' => 'object',
    'subtype' => 'blog',
]);

$layout = elgg_view_layout('default', [
    'title' => $title,
    'content' => $content,
]);

echo elgg_view_page($title, $layout);

// after
echo elgg_view_page('All blogs', [
    'content' => elgg_list_entities([
        'type' => 'object',
        'subtype' => 'blog',
    ]),
]);
```

## Deprecated layout names

The legacy layout names kept for the 2.x to 3.x transition — `one_sidebar`,
`one_column`, `two_sidebar`, and `content` — are deprecated as of 3.3;
update your code to use the `default` layout. Note that the `content`
layout generates a filter menu that differs from the regular `filter` menu
of the `default` layout and uses different hook names. If the filter is
already disabled in your layout, you can change the layout without issues.

## Plugin manifest changes

The plugin manifest file is being phased out — some manifest features will
be replaced or dropped. The following `ElggPluginManifest` API functions
are already deprecated:

- `getCopyright()`
- `getDonationsPageURL()`
- `getSuggests()` — use composer suggestions

## Deprecated APIs

- `elgg_disable_query_cache()`
- `elgg_enable_query_cache()`
- `elgg_format_attributes()` — use `elgg_format_element()`
- `elgg_flush_caches()` — use `elgg_clear_caches()`
- `elgg_get_menu_item()`
- `elgg_get_ordered_event_handlers()` — use
  `elgg()->events->getOrderedHandlers()`
- `elgg_get_ordered_hook_handlers()` — use
  `elgg()->hooks->getOrderedHandlers()`
- `elgg_invalidate_simplecache()` — use `elgg_clear_caches()`
- `elgg_is_menu_item_registered()`
- `elgg_view_entity_annotations()`
- `execute_delayed_write_query()` — use `elgg()->db->registerDelayedQuery()`
- `execute_delayed_read_query()` — use `elgg()->db->registerDelayedQuery()`
- `run_sql_script()`
- `elgg_unset_all_plugin_settings()` — use `\ElggPlugin::unsetAllSettings()`
- `elgg_get_file_simple_type()` — use `elgg()->mimetype->getSimpleType()`
- `ElggFile::detectMimeType()` — use `elgg()->mimetype->getMimeType()`
- `generate_action_token()` — use `elgg()->csrf->generateActionToken()`
- `elgg_split()`

## Deprecated config values

- `simplecache_lastupdate` — use `lastcache`

## Deprecated CLI commands

- `elgg-cli flush` — use `elgg-cli cache:clear`

## Deprecated hooks

- `entity:annotate, <entity_type>`
