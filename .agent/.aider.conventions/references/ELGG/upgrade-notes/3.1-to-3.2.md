# Plugin Upgrade Notes: 3.1 to 3.2

Delta guidance for updating Elgg plugins from 3.1 to 3.2, distilled from
<https://learn.elgg.org/en/stable/appendix/upgrade-notes/3.1-to-3.2.html>.
The transition moves write-access collection subtype registration behind a
plugin hook and deprecates the `enabled` state of river items.

## User write access

User-owned access collections such as `Friends` or `Friend Collections` no
longer appear automatically in the write-access drop-down when creating
content. To offer an access collection subtype in the write access,
register the subtype with the `access:collections:write:subtypes` plugin
hook (see the access hooks section of the plugin hook reference).

## River items

The `enabled` state of river items is deprecated. Do not use this property
when working with river items.
