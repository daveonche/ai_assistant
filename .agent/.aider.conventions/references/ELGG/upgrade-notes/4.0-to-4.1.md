# Plugin Upgrade Notes: 4.0 to 4.1

Delta guidance for updating Elgg plugins from 4.0 to 4.1, distilled from
<https://learn.elgg.org/en/stable/appendix/upgrade-notes/4.0-to-4.1.html>.
The transition introduces entity capabilities to replace the registered
entity types system, adds threaded comments behind a site setting, and
deprecates a small set of lib functions and plugin hooks.

## Entity capabilities

A new way of registering entity capabilities has been introduced; the
currently implemented capabilities are `commentable`, `likable` and
`searchable`. The following related functions have been deprecated:

- `elgg_register_entity_type()` — use
  `elgg_entity_enable_capability($type, $subtype, 'searchable')`
- `elgg_unregister_entity_type()` — use
  `elgg_entity_disable_capability($type, $subtype, 'searchable')`
- `get_registered_entity_types()` — use
  `elgg_entity_types_with_capability('searchable')`
- `is_registered_entity_type()` — use
  `elgg_entity_has_capability($type, $subtype, 'searchable')`

The config variable `registered_entities` is no longer available.

## Threaded comments

Support for threaded comments has been added; the feature needs to be
enabled in the site settings. Changes were made to the comments-related
JavaScript and CSS, so custom styling or features built on the comment
views may need extra attention.

## Deprecated APIs

### Lib functions

- `elgg_get_version()` — use `elgg_get_release()`
- `get_user_by_code()` — use `elgg_get_user_by_persistent_token()`;
  you only need to provide the token, not the hashed token

### Plugin hooks

- `'likes:is_likable', '<type>:<subtype>'` — use
  `$entity->hasCapability('likable')`
