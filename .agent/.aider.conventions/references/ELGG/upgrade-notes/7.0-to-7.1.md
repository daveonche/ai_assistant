# Plugin Upgrade Notes: 7.0 to 7.1

Delta guidance for updating Elgg plugins from 7.0 to 7.1, distilled from
<https://learn.elgg.org/en/stable/appendix/upgrade-notes/7.0-to-7.1.html>.
The transition switches the default database recommendation from MySQL to
MariaDB, raises the minimal MySQL version to 8.4, deprecates the per-entity
`resources/*` routes in favor of the generic entity controller, splits the
default filter menu tab handlers, and deprecates the `forms/pages/edit`
view.

## Databases

- The default database recommendation is now MariaDB — fully compatible
  with MySQL data and table definitions, with improved performance
- The minimal MySQL version is now 8.4

## Generic entity controller

The following resources are deprecated because of the introduction of the
generic entity controller:

- `resources/blog/add`
- `resources/blog/edit`
- `resources/blog/view`
- `resources/bookmarks/add`
- `resources/bookmarks/edit`
- `resources/bookmarks/view`
- `resources/discussion/add`
- `resources/discussion/edit`
- `resources/discussion/view`
- `resources/file/edit`
- `resources/file/upload`
- `resources/file/view`
- `resources/pages/add`
- `resources/pages/edit`
- `resources/pages/view`
- `resources/thewire/view`

## Generic filter menu items

- The generic menu items registered to the default filter menu ('All',
  'Mine', 'Friends') no longer show on pages with an owner different from
  the logged-in user
- The event handler for the 'All' and 'Mine' menu items is split into 2
  separate event handlers
- `\Elgg\Menus\Filter::registerFilterTabs` is replaced by
  `\Elgg\Menus\Filter::registerAllFilterTab` and
  `\Elgg\Menus\Filter::registerMineFilterTab`
- Passing custom `elgg_view_page()` variables ('all_link', 'mine_link',
  'friend_link') is deprecated — leverage the generic route names for
  these kinds of pages

## Deprecated Views

- `forms/pages/edit` — use `forms/page/edit`
