# Plugin Upgrade Notes: 6.2 to 6.3

Delta guidance for updating Elgg plugins from 6.2 to 6.3, distilled from
<https://learn.elgg.org/en/stable/appendix/upgrade-notes/6.2-to-6.3.html>.
The transition is deprecation-only: the debug dump and user notification
functions, direct use of `\ElggObject`, and `\Elgg\Logger::dump()` are
deprecated, each with a stated replacement.

## Deprecated APIs

- `elgg_dump()` — use `elgg_log()` as a replacement
- `notify_user()` — use `elgg_notify_user()` or `\ElggUser::notify()` as
  a replacement

## Deprecated Classes

- Using `\ElggObject` directly — use your own extension of `ElggObject`
  for your subtype

## Deprecated Class Functions

- `\Elgg\Logger::dump()` — use `\Elgg\Logger::error()` as a replacement
