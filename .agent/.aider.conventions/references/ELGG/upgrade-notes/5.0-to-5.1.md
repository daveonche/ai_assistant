# Plugin Upgrade Notes: 5.0 to 5.1

Delta guidance for updating Elgg plugins from 5.0 to 5.1, distilled from
<https://learn.elgg.org/en/stable/appendix/upgrade-notes/5.0-to-5.1.html>.
The transition reshapes the page DOM for accessibility — some sections
change from `div` to `header`, `main` or `footer` — and deprecates the
`page/elements/<section>/before` and `page/elements/<section>/after`
views plus the comment-editing resource and route.

## Changes in the DOM structure

In order to improve accessibility, some page sections changed from a
`div` to `header`, `main` or `footer`. The classes and the place in the
DOM are unchanged.

## Deprecated Views

- `page/elements/<section>/after` — extend the correct
  `page/elements/<section>`
- `page/elements/<section>/before` — prepend the correct
  `page/elements/<section>`
- `resources/comments/edit` — this resource is no longer in use

## Deprecated Routes

- `edit:object:comment` — editing comments uses an inline form
