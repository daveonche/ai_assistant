# Elgg Developer Guide: Events List — Files

Category table for the events-list distillation: marker legend and the
behavioral traps live in `../events-list.md`. Distilled from the stable
manual on 2026-09-30 (source: `docs/guides/events-list.rst`, Elgg ref
`7.1`); update in place when the stable manual changes.

## Download and inline URLs

| Event | Marker | Notes |
| :--- | :--- | :--- |
| `download:url, file` | results | filter the download URL of the file; by default the URL is generated by the file service; `$params`: `entity` (an `ElggFile`), `use_cookie` (whether a cookie secures the download link), `expires` (string representation of when the link expires) |
| `inline:url, file` | results | filter the inline URL of the image file; by default the URL is generated by the file service; `$params`: `entity`, `use_cookie`, `expires` |

## Mimetype detection

| Event | Marker | Notes |
| :--- | :--- | :--- |
| `mime_type, file` | results | return the mimetype for the filename `$params['filename']`, with original filename `$params['original_filename']` and default detected mimetype `$params['default']` |
| `simple_type, file` | results | receives `$params['mime_type']` (e.g. `application/pdf`, `image/jpeg`) and determines an overall category like `document` or `image`; the bundled file plugin and third-party plugins usually store `simpletype` metadata on file entities and use it when serving icons and constructing `ege*` filters and menus |

## Upload

| Event | Marker | Notes |
| :--- | :--- | :--- |
| `upload, file` | results | implement custom logic for moving an uploaded file into an `ElggFile`; return `true` if the file was moved, `false` if it could not be moved; any other return lets `ElggFile::acceptUploadedFile` proceed with the default upload logic; `$params`: `file` (the `ElggFile` to write to), `upload` (Symfony's `UploadedFile`) |
| `upload:after, file` | | after an uploaded file has been written to the filestore; receives the `ElggFile` the upload was written to — it may or may not be an entity with a GUID |
