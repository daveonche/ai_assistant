# Plugin Upgrade Notes: 2.1 to 2.2

Delta guidance for updating Elgg plugins from 2.1 to 2.2, distilled from
<https://learn.elgg.org/en/stable/appendix/upgrade-notes/2.1-to-2.2.html>.
The transition deprecates legacy JS libraries in favor of AMD modules,
introduces the entity icon API and `serve-file`-based asset serving, and
removes private entity cache functions.

## Deprecated APIs

- `elgg.ui.river` JavaScript library — remove `elgg_load_js('elgg.ui.river')`
  calls from plugin code; update `core/river/filter` and
  `forms/comment/save` overrides to require the component AMD modules.
- `elgg.ui.popupOpen()` and `elgg.ui.popupClose()` — use the `elgg/popup`
  module instead.
- `lightbox.js` library — do not use `elgg_load_js('lightbox.js')` unless
  the code references the deprecated `elgg.ui.lightbox` namespace; use the
  `elgg/lightbox` AMD module instead.
- `elgg.embed` library and `elgg.embed` object — do not use
  `elgg_load_js('elgg.embed')`; use the `elgg/embed` AMD module instead.
- Accessing the `icons_sizes` config value directly — use
  `elgg_get_icon_sizes()`.
- `can_write_to_container()` — use `ElggEntity::canWriteToContainer()`.

## Deprecated views

- `elgg/ui.river.js` — do not rely on its simplecache URL.
- `groups/js` — use the `groups/navigation` AMD module as a menu item
  dependency for the "feature" and "unfeature" menu items.
- `lightbox/settings.js` — use the `getOptions, ui.lightbox` JS plugin hook
  or the `data-colorbox-opts` attribute.
- `elgg/ckeditor/insert.js` — no longer needs to be included; hook
  registration takes place in the `elgg/ckeditor` module.
- `embed/embed.js` — use the `elgg/embed` AMD module.

## Added `elgg/popup`, `elgg/lightbox`, and `elgg/embed` modules

- `elgg/popup` builds more complex trigger-popup interactions, including
  binding custom anchor types and opening/closing popups programmatically.
- `elgg/lightbox` opens and closes the lightbox programmatically.
- `elgg/embed` accesses the embed methods programmatically; it bootstraps
  itself when necessary and is unlikely to require further decoration.

All three are documented in
<https://learn.elgg.org/en/stable/guides/javascript.html>.

## New API for handling entity icons

- `ElggEntity` now implements the `\Elgg\EntityIcon` interface.
- `elgg_get_icon_sizes()` returns entity type/subtype specific icon sizes.
- `ElggEntity::saveIconFromUploadedFile()` creates icons from an uploaded
  file.
- `ElggEntity::saveIconFromLocalFile()` creates icons from a local file.
- `ElggEntity::saveIconFromElggFile()` creates icons from an `ElggFile`
  instance.
- `ElggEntity::getIcon()` returns an `ElggIcon` pointing to the icon's
  filestore location (possibly just a placeholder — validate with
  `ElggEntity::hasIcon()`).
- `ElggEntity::deleteIcon()` deletes entity icons.
- `ElggEntity::getIconLastChange()` returns the icon file's modified time.
- `ElggEntity::hasIcon()` checks whether an icon of a given size exists.
- `elgg_get_embed_url()` returns an embed URL for an entity's icon (served
  via the `/serve-icon` handler).

### User avatars

Served via the `serve-file` handler; use `elgg_get_inline_url()`. Note:

- The `/avatar/view` page handler and resource view are deprecated.
- `mod/profile/icondirect.php` is deprecated.
- `profile_set_icon_url()` is no longer registered as a callback for the
  `"entity:icon:url", "user"` plugin hook.

### Group avatars

Served via the `serve-file` handler; use `elgg_get_inline_url()`. Note:

- The `groupicon` page handler (`groups_icon_handler()`) is deprecated.
- `mod/groups/icon.php` is deprecated.

### File entity thumbs and downloads

Served via the `serve-file` handler; use `elgg_get_inline_url()` and
`elgg_get_download_url()`. Note:

- The `file/download` page handler and resource view are deprecated.
- `mod/file/thumbnail.php` is deprecated.
- Several views were updated to the new download URLs, including
  `mod/file/views/default/file/specialcontent/audio/default.php`,
  `mod/file/views/default/file/specialcontent/image/default.php`,
  `mod/file/views/default/resources/file/view.php`, and
  `mod/file/views/rss/file/enclosure.php`.

## Removed APIs

The private entity cache functions (e.g. `_elgg_retrieve_cached_entity`)
have been removed. Plugins should not use private APIs, which are more
often removed without notice.

## Improved `elgg/ckeditor` module

The `elgg/ckeditor` module can add WYSIWYG to a textarea programmatically
with `elgg/ckeditor#bind` — see
<https://learn.elgg.org/en/stable/guides/javascript.html>.
