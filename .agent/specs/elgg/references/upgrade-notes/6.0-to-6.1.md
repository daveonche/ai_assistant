# Plugin Upgrade Notes: 6.0 to 6.1

Delta guidance for updating Elgg plugins from 6.0 to 6.1, distilled from
<https://learn.elgg.org/en/stable/appendix/upgrade-notes/6.0-to-6.1.html>.
The transition is deprecation-only: the legacy `ELGG_CACHE_*` constants
move to class constants on `\Elgg\Cache\CompositeCache`, and the
simplecache/system cache management functions plus `elgg_plugin_exists()`
are deprecated.

## Constants

- `ELGG_CACHE_BLACK_HOLE` — deprecated; use
  `\Elgg\Cache\CompositeCache::CACHE_BLACK_HOLE`
- `ELGG_CACHE_RUNTIME` — deprecated; use
  `\Elgg\Cache\CompositeCache::CACHE_RUNTIME`
- `ELGG_CACHE_FILESYSTEM` — deprecated; use
  `\Elgg\Cache\CompositeCache::CACHE_FILESYSTEM`
- `ELGG_CACHE_PERSISTENT` — deprecated; use
  `\Elgg\Cache\CompositeCache::CACHE_PERSISTENT`
- `ELGG_CACHE_LOCALFILESYSTEM` — deprecated; use
  `\Elgg\Cache\CompositeCache::CACHE_LOCALFILESYSTEM`

## Deprecated APIs

- `elgg_disable_simplecache()`
- `elgg_disable_system_cache()`
- `elgg_enable_simplecache()`
- `elgg_enable_system_cache()`
- `elgg_get_system_cache()`
- `elgg_is_simplecache_enabled()`
- `elgg_is_system_cache_enabled()`
- `elgg_plugin_exists()` — use `elgg_get_plugin_from_id()` as a replacement
- `elgg_reset_system_cache()`
