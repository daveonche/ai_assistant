# Plugin Upgrade Notes: 1.10 to 1.11

Delta guidance for updating Elgg plugins from 1.10 to 1.11, distilled from
<https://learn.elgg.org/en/stable/appendix/upgrade-notes/1.10-to-1.11.html>.
The only documented change concerns comment highlighting: themes overriding
the components stylesheet must add the highlight styles themselves.

## Comment highlighting

If a theme overrides `views/default/css/elements/components.php`, add the
following style definitions to it to enable highlighting for comments and
discussion replies:

```css
.elgg-comments .elgg-state-highlight {
    -webkit-animation: comment-highlight 5s;
    animation: comment-highlight 5s;
}
@-webkit-keyframes comment-highlight {
    from {background: #dff2ff;}
    to {background: white;}
}
@keyframes comment-highlight {
    from {background: #dff2ff;}
    to {background: white;}
}
```
