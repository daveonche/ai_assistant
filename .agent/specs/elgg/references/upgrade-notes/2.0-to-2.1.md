# Plugin Upgrade Notes: 2.0 to 2.1

Delta guidance for updating Elgg plugins from 2.0 to 2.1, distilled from
<https://learn.elgg.org/en/stable/appendix/upgrade-notes/2.0-to-2.1.html>.
The transition deprecates several filestore and URL APIs, changes the
object returned by `Application::getDb()`, and adds the `elgg/widgets`
AMD module.

## Deprecated APIs

- `ElggFile::setFilestore`
- `get_default_filestore`
- `set_default_filestore`
- `elgg_get_config('siteemail')` — use `elgg_get_site_entity()->email`
- URLs starting with `/css/` and `/js/` — use `elgg_get_simplecache_url()`
- The `elgg.ui.widgets` JavaScript object — deprecated by the
  `elgg/widgets` AMD module

## `Application::getDb()` changes

If you use this low-level API, do not expect it to return an
`Elgg\Database` instance in 3.0. It now returns an
`Elgg\Application\Database` with many methods deprecated. These methods
were never meant to be public API, but they will be supported as well as
possible throughout 2.x.

## Added `elgg/widgets` module

If plugin code calls `elgg.ui.widgets.init()`, use the `elgg/widgets` AMD
module instead — see
<https://learn.elgg.org/en/stable/guides/javascript.html>.
