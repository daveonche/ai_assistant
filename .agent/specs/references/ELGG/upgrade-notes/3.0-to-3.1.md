# Plugin Upgrade Notes: 3.0 to 3.1

Delta guidance for updating Elgg plugins from 3.0 to 3.1, distilled from
<https://learn.elgg.org/en/stable/appendix/upgrade-notes/3.0-to-3.1.html>.
The transition raises the PHP requirement for new installations, drops
plugin screenshots and core simpletests, discourages the legacy JS/CSS
registration APIs in favor of `elgg_require_js()`/`elgg_require_css()`,
and deprecates legacy hook/event callback signatures along with a batch
of APIs, routes, libraries, and actions.

## PHP version

PHP 7.0 reached end of life in January 2019; new installations now
require PHP 7.1. Installations upgrading from a previous Elgg version
must have the correct PHP version installed.

## Plugin screenshots

Screenshots added to plugins are no longer supported and are no longer
shown in the plugin details.

## Loading external files

- `elgg_register_js()`, `elgg_unregister_js()`, and `elgg_load_js()` are
  discouraged. Make the JavaScript an AMD module and include it with
  `elgg_require_js()`.
- `elgg_register_css()`, `elgg_unregister_css()`, and `elgg_load_css()`
  are discouraged. Register and include CSS with the new
  `elgg_require_css()` function.

## Setting page owner

Setting the page owner via the `elgg_get_page_owner_guid()` function
parameter is deprecated. Use `elgg_set_page_owner_guid()`.

## Simpletests

The core simpletests have been removed from the system; they are all
replaced by PHPUnit tests or integration tests. The simpletest CLI
command is deprecated.

## Hook and event callbacks

The legacy style hook and event callback arguments are deprecated.
Switch to the new style as soon as possible.

```php
// old style hook callback
function hook_callback($name, $type, $return_value, $params) {

}

// new style hook callback
function hook_callback(\Elgg\Hook $hook) {
    // now you can use a few new functions
    $params = $hook->getParams();
    $return = $hook->getValue();

    $specific_param = $hook->getParam('specific_param', 'default');
    $entity = $hook->getEntityParam();
    $user = $hook->getUserParam();
}

// old style event callback
function event_callback($name, $type, $object) {

}

// new style event callback
function event_callback(\Elgg\Event $event) {
    // now you can use a few new functions
    $object = $event->getObject();
}
```

## Deprecated routes

- `previous:object:thewire` — this route was not in use; it is now
  marked as deprecated.

## Deprecated CSS libraries

- `jquery.imgareaselect` — do not use this external CSS file.
- `jquery.treeview` — do not use this external CSS file.

## Deprecated JS libraries

- `elgg.avatar_cropper` — do not depend on this external JavaScript
  library.
- `jquery.imgareaselect` — do not depend on this external JavaScript
  library.
- `jquery.treeview` — do not depend on this external JavaScript library.

## Deprecated APIs

- `access_show_hidden_entities()` — use `elgg_call()` with the
  `ELGG_SHOW_DISABLED_ENTITIES` flag.
- `autoregister_views()`
- `count_messages()` — use `elgg()->system_messages->count()`.
- `disable_user_entities()`
- `elgg_enable_entity()` — use `ElggEntity::enable()`.
- `elgg_get_file_list()` — use a PHP directory iterator.
- `elgg_instanceof()` — use the PHP `instanceof` type operator.
- `elgg_is_admin_user()` — use `ElggUser::isAdmin()`.
- `elgg_set_ignore_access()` — use `elgg_call()` with the
  `ELGG_IGNORE_ACCESS` flag.
- `elgg_sort_3d_array_by_value()`
- `get_access_list()` — use `get_access_array()`.
- `get_language()` — use `get_current_language()`.
- `get_number_users()` — use `elgg_count_entities()`.
- `pages_register_navigation_tree()`
- `ini_get_bool()`
- `is_not_null()`
- `update_access_collection()`

## Deprecated actions

- `admin/delete_admin_notice` — replaced by the generic entity/delete
  action.
- `avatar/crop` — handled in the avatar/upload action.
- `avatar/remove` — handled in the avatar/upload action.
- `blog/delete` — replaced by the generic entity/delete action.
- `messages/delete` — replaced by the generic entity/delete action.
- `site_notifications/delete` — replaced by the generic entity/delete
  action.
