# Plugin Upgrade Notes: 1.9 to 1.10

Delta guidance for updating Elgg plugins from 1.9 to 1.10, distilled from
<https://learn.elgg.org/en/stable/appendix/upgrade-notes/1.9-to-1.10.html>.
The only documented change concerns file uploads: the mime-type workaround
copied from the `file/upload` action is no longer needed, and mime and
simple-type filtering is recommended via plugin hooks.

## File uploads

If a plugin uses a snippet copied from the `file/upload` action to fix
detected mime types for Microsoft zipped formats, the snippet can now be
safely removed.

If the upload action performs other manipulations on detected mime and
simple types, use the available plugin hooks instead:

- Use `'mime_type','file'` to filter detected mime types.
- Use `'simple_type','file'` to filter parsed simple types.
