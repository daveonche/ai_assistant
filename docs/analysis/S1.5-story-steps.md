Story S1.5 Implementation Steps:

Step 1. Enable Prompt Directory Structure Creation
Must Support:
- Creation of the `.aider.prompt/` directory in the project root
- Creation of subdirectories for core categories (e.g., planning, coding, architecture, requirements, documentation, testing)
Manual Verification:
- Verify the `.aider.prompt/` directory exists in the project root
- Verify subdirectories for core categories exist within `.aider.prompt/`
Prerequisite: None
Developer Notes:
- Create a standard directory structure to organize prompt files by their functional area.

Step 2. Enable Core Prompt File Integration
Must Support:
- Addition of `SKILL.md` files into the respective category subdirectories
- Addition of `SKILL.meta.md` files containing usage documentation for each prompt
- Each `SKILL.md` file must define a specific workflow or skill
Manual Verification:
- Verify `SKILL.md` files are present in the core category subdirectories
- Verify `SKILL.meta.md` files are present alongside the `SKILL.md` files
- Verify the contents of the `SKILL.md` files define structured workflows
- Verify the contents of the `SKILL.meta.md` files provide usage documentation
Prerequisite: Step 1
Developer Notes:
- Ensure prompt files follow the standard `SKILL.md` format and contain clear, staged instructions.
- Include usage documentation in the `SKILL.meta.md` files to explain how to use the prompts.

Step 3. Enable Shorthand Command Mapping
Must Support:
- Definition of shorthand syntax (`$<category>-<promptname>`) in `AGENT.md`
- Mapping of shorthand commands to the corresponding `SKILL.md` file paths
Manual Verification:
- Verify `AGENT.md` contains the shorthand syntax definition
- Verify the mapping correctly resolves to the file paths
Prerequisite: Step 2
Developer Notes:
- Update the orchestrator file to recognize and process the shorthand commands.

Step 4. Enable Prompt Loading and Dropping Verification
Must Support:
- Aider's ability to load a prompt file into context using the defined commands
- Aider's ability to remove a prompt file from context using the defined commands
- Workflow instructions in `AGENT.md` that guide the user through loading and dropping
Manual Verification:
- Verify Aider can load a prompt using a shorthand command (e.g., `$planning-vision-statement`)
- Verify Aider can drop a prompt using the defined drop command
- Verify the `AGENT.md` instructions correctly guide the user through the process
Prerequisite: Step 3
Developer Notes:
- Test the context management commands to ensure prompts can be added and removed dynamically.
