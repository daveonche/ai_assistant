Story S1.5 Implementation Steps:

Step 1. Enable prompt directory structure
Must Support:
- Creation of the `.aider.prompt/` directory.
- Creation of subdirectories for core categories (e.g., planning, coding, architecture).
Manual Verification:
- Check that the `.aider.prompt/` directory exists in the project root.
- Verify that subdirectories for categories are present.
Prerequisite: None
Developer Notes:
- Consider organizing prompts by their functional area to maintain a clean structure.

Step 2. Enable prompt file creation
Must Support:
- Creation of `SKILL.md` files within the category subdirectories.
- Definition of prompt instructions and behaviors inside `SKILL.md`.
Manual Verification:
- Open a `SKILL.md` file and verify it contains valid prompt instructions.
- Ensure files are named consistently as `SKILL.md`.
Prerequisite: Step 1
Developer Notes:
- Use a standard format for all prompt files to ensure consistency.

Step 3. Enable shorthand command mapping
Must Support:
- Configuration that maps `$<category>-<promptname>` commands to specific `SKILL.md` files.
- Recognition of shorthand commands by the AI assistant.
Manual Verification:
- Attempt to use a shorthand command (e.g., `$planning-vision-statement`).
- Observe if the assistant recognizes the command and attempts to load the corresponding prompt.
Prerequisite: Step 2
Developer Notes:
- Ensure the mapping logic is intuitive and follows the directory structure.

Step 4. Enable context management rules in AGENT.md
Must Support:
- Creation or update of `AGENT.md` with instructions for loading and dropping prompts.
- Use of `/read-only` and `/drop` commands as specified in `AGENT.md`.
Manual Verification:
- Review `AGENT.md` to ensure it contains context management rules.
- Instruct the assistant to load a prompt and verify it uses `/read-only`.
- Instruct the assistant to drop a prompt and verify it uses `/drop`.
Prerequisite: Step 3
Developer Notes:
- Clearly define the lifecycle of a prompt in the context window to optimize token usage.

Step 5. Enable prompt loading and dropping verification
Must Support:
- The AI assistant must successfully load the contents of a `SKILL.md` file into its context.
- The AI assistant must successfully remove the contents of a `SKILL.md` file from its context.
Manual Verification:
- Trigger a prompt load and confirm the assistant acknowledges the file is in context.
- Trigger a prompt drop and confirm the assistant acknowledges the file is removed.
Prerequisite: Step 4
Developer Notes:
- Verify that the assistant's behavior changes according to the loaded prompt.
